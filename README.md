# BLE Mission — Android app

แอป Android ธีม BLE Mission สำหรับโจทย์ Bluetooth LE ในชั้นเรียน ใช้ Service UUID `aee04821-1973-4e1f-a590-e84b10d580e7` และ Characteristic UUID `cde07b1a-889b-44b7-a99f-c888dddac729`

แอปเวอร์ชัน 2.3 มีธีมจรวดและภูเขาตามภาพตัวอย่าง จรวดลอย เมฆเลื่อน แสงอาทิตย์และประกายเคลื่อนไหว และจรวดบินสูงขึ้นเมื่อได้ผลจากอุปกรณ์ ปุ่ม `II`/`▶` ด้านบนใช้หยุดหรือเล่นภาพเคลื่อนไหว (จำค่าที่เลือก) พร้อมแถบความคืบหน้า ปุ่มสลับไทย/อังกฤษ บันทึกเวลาของแต่ละด่าน ปุ่มคัดลอก/แชร์ผลหลังจบภารกิจ ปุ่มเริ่มใหม่ และการสั่นตอบรับเมื่อส่งชื่อหรือรับผลสำเร็จ รายการสแกนจะอัปเดตชื่อหากอุปกรณ์ส่งชื่อมาในสัญญาณถัดไป และทำเครื่องหมาย ★ เมื่อพบ Service UUID ตรงโจทย์ในสัญญาณ BLE

## เงื่อนไขโจทย์

- เชื่อมต่ออุปกรณ์ BLE ที่มี Service UUID และ Characteristic UUID ตามที่ระบุด้านบน
- อ่านค่า Characteristic ครั้งแรกจากอุปกรณ์
- ส่งชื่อคุณและชื่อเพื่อนเป็นข้อความ UTF-8 ค่าเริ่มต้น `ชื่อคุณ,ชื่อเพื่อน` โดยแก้รูปแบบข้อความได้
- อ่าน Characteristic เดิมอีกครั้งและแสดงคำตอบที่อุปกรณ์ส่งกลับ แอปไม่สร้างเกรดเอง
- ผู้ใช้ต้องจับภาพหน้าจอผลจากเครื่องอาจารย์จริงและส่ง Google Classroom ในวันเรียน

## ติดตั้งบนโทรศัพท์

1. คัดลอก `BLEMission.apk` ไปยังโทรศัพท์ Android 8.0 หรือใหม่กว่า ที่รองรับ BLE
2. เปิดไฟล์ APK และอนุญาตการติดตั้งจากแหล่งนี้ หากโทรศัพท์ถาม
3. เปิด Bluetooth เปิดแอป และอนุญาต "อุปกรณ์ใกล้เคียง" (Android 12 ขึ้นไป) หรือสิทธิ์ตำแหน่งสำหรับการสแกน (Android 8–11)
4. กด **ค้นหาอุปกรณ์ BLE** เลือกอุปกรณ์ของอาจารย์
5. ทำด่าน 1 อ่านค่า → ด่าน 2 กรอกชื่อสองคนแล้วส่ง → ด่าน 3 อ่านอีกครั้ง
6. แคปหน้าจอที่แสดงค่าจากอุปกรณ์จริงเพื่อส่งงาน

ข้อความเริ่มต้นใช้รูปแบบ `ชื่อคุณ,ชื่อเพื่อน` เป็น UTF-8 สามารถแก้ช่อง "ข้อความที่จะส่ง" ก่อนส่งได้ หากอาจารย์กำหนดรูปแบบอื่น ค่าเกรดที่แสดงมาจากอุปกรณ์ แอปไม่คำนวณเอง

## เปิดโปรเจกต์เพื่อแก้ไข

เปิดโฟลเดอร์นี้ (`D:\BT\project`) ใน Android Studio แล้วรอ Gradle Sync โปรเจกต์ใช้ Java, Android SDK 36, Gradle 9.3.1 และ Android Gradle Plugin 8.12.0 จากนั้นเลือก Build > Build APK(s)

ไฟล์ `BLEMission.apk` เป็น **debug APK ที่เซ็นชื่อแล้ว** สำหรับติดตั้งทดสอบในชั้นเรียน หากแก้โค้ดและสร้าง APK ใหม่ ควรใช้ไฟล์ใหม่จาก `app\build\outputs\apk\debug\app-debug.apk`

## ข้อจำกัดการทดสอบ

ทดสอบการคอมไพล์ การติดตั้ง และเปิดหน้าจอบน Android Emulator แล้ว แต่ Emulator ไม่มีอุปกรณ์ BLE ของอาจารย์ จึงยังยืนยันผลกับเครื่องอาจารย์ไม่ได้

### ทดสอบด้วยโทรศัพท์หนึ่งเครื่องและโน้ตบุ๊กเครื่องนี้

1. เปิด Bluetooth ทั้งโทรศัพท์และโน้ตบุ๊ก แล้ววางไว้ใกล้กัน
2. โน้ตบุ๊กต้องมี Python 3.9 หรือใหม่กว่า จากนั้นดับเบิลคลิก `start-test-device.cmd` และเปิดหน้าต่างนั้นค้างไว้จนเห็น `BLE Mission test device is running.` ครั้งแรกที่รันจาก GitHub สคริปต์จะติดตั้งไลบรารี Python ตาม `simulator/requirements.txt` ให้อัตโนมัติ
3. ติดตั้ง `BLEMission.apk` รุ่น 2.3 บนโทรศัพท์ เปิดแอปและกดค้นหา BLE
4. เลือกรายการที่มี `★ UUID ตรงโจทย์` หรือ `★ Assignment UUID match` ถ้ารายการไม่มีชื่อ ให้ใช้เครื่องหมายนี้ช่วยแยกจากอุปกรณ์อื่น หากไม่มีเครื่องหมาย ★ ให้ปิดตัวจำลอง สแกนหนึ่งครั้ง จากนั้นเปิดตัวจำลองและสแกนใหม่เพื่อดูว่ารายการใดเพิ่มขึ้น
5. กดอ่านครั้งแรก ต้องได้ `68`
6. กรอกชื่อคุณและเพื่อน แล้วกดส่ง ดูหน้าต่างโน้ตบุ๊กว่าขึ้น `WRITE <- ...`
7. กดอ่านครั้งที่สอง ต้องได้ `TEST OK` และในหน้าต่างโน้ตบุ๊กต้องมี `READ -> TEST OK`
8. ปิดตัวจำลองโดยกด Ctrl+C ในหน้าต่างโน้ตบุ๊ก

`TEST OK` เป็นผลจำลองเพื่อเช็กการรับส่ง BLE เท่านั้น ไม่ใช่เกรดจากเครื่องอาจารย์ ไม่ควรใช้ภาพผลจำลองส่งเป็นผลคะแนนจริง ตัวจำลองใช้ UUID จริงตามโจทย์ แต่พฤติกรรมและรูปแบบคำตอบของเครื่องอาจารย์ยังต้องทดสอบในวันเรียน

ถ้ารายการขึ้น "อุปกรณ์ไม่มีชื่อ" แปลว่าโทรศัพท์ยังไม่ได้รับชื่อจากโฆษณา BLE หรือระบบ ชื่อจะอัปเดตถ้ามาถึงภายหลัง รายการที่ไม่มีเครื่องหมาย ★ อาจเป็นอุปกรณ์อื่น หรืออุปกรณ์ที่ไม่ประกาศ Service UUID ในสัญญาณ แม้ว่าจะมี Service หลังเชื่อมต่อ
